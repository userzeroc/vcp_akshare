## 一、模块概述

股性分析模块通过**四个维度**对 A 股股票进行全面的"性格画像"，最终将股票归类为 A/B/C/D 四个抽屉，并给出对应的交易战术建议。

**核心理念**：每只股票都有自己独特的"脾气"和"习惯"，了解股性才能制定正确的交易策略。用对方法做对股。

### 四个抽屉

| 抽屉 | 名称 | 标识 | 股性特征 | 交易战术 |
|:---|:---|:---|:---|:---|
| **A** | 白马/核心资产 | 🐎 | 稳、沉、缩量、机构控盘 | 网格交易/定投，大跌大买，时间换空间 |
| **B** | 题材龙头/妖股 | 🐉 | 爆、连板、高换手、游资主导 | 右侧跟随，严设止损，跌破5日线清仓 |
| **C** | 渣男/宽幅震荡 | 💔 | 上影线多、过山车、炸板率高 | 反人性操作，涨到压力位必卖，跌到支撑位敢买 |
| **D** | 僵尸股 | 💀 | 直线画图、成交低迷、跟跌不跟涨 | 直接删自选，无论跌多少都不买 |

## 二、自动过滤规则

以下股票**不参与分析**，一律视为不可交易：

| 类型 | 判定规则 | 原因 |
|:---|:---|:---|
| **ST 股票** | 名称包含 `ST`（含 `*ST`、`SST`、`S*ST`） | 风险极高，不适合短线/趋势交易 |
| **北交所股票** | `market == "北交所"` | 流动性差，涨跌幅30%不具可比性 |

## 三、自适应机制

### 3.1 涨停阈值自适应

系统根据股票所属板块自动调整涨停板判定阈值：

| 板块 (`market` 字段) | 涨停阈值 | 说明 |
|:---|:---|:---|
| 主板 | **9.8%** | `pct_chg >= 9.8` 视为涨停 |
| 创业板 | **19.5%** | 2020年注册制后涨跌幅放宽至20% |
| 科创板 | **19.5%** | 同创业板规则 |

> **为什么不用整数 10%/20%？** 因为实际涨停价格有精度截断，实际涨幅通常略低于理论值（如 9.97%），用 9.8% 和 19.5% 作为阈值可以避免遗漏。

### 3.2 大盘基准自适应

维度四（江湖地位）需要对比个股与大盘的表现。系统自动选择最匹配的基准指数：

| 板块 | 基准指数 | 代码 |
|:---|:---|:---|
| 主板 | 上证指数 | `000001.SH` |
| 创业板 | 创业板指 | `399006.SZ` |
| 科创板 | 科创50 | `000688.SH` |

### 3.3 时间衰减权重

分析窗口默认 **3 年**（750 个交易日），但近期数据的权重更高：

| 时间距今 | 权重 | 说明 |
|:---|:---|:---|
| 0 ~ 6 个月 | **1.0** | 最近的表现最重要 |
| 6 ~ 12 个月 | **0.7** | 近一年的行为仍有参考价值 |
| 1 ~ 2 年 | **0.4** | 可能已换主力，权重降低 |
| 2 ~ 3 年 | **0.2** | 仅作统计参考 |

> **用途**：当前仅作用于维度一（脾气）的振幅加权计算。一只股票 2 年前频繁涨停但近 1 年沉寂，衰减后应判定为"已失去妖股基因"。

## 四、四个维度详解

### 4.1 维度一：看"脾气" —— 波动率与涨停基因

**核心目标**：测量股票在极端情绪下的爆发力，区分"平庸股"和"龙头妖股"。

#### 计算指标

| 指标 | 计算方式 | 诊断意义 |
|:---|:---|:---|
| 涨停次数 | `pct_chg >= 涨停阈值` 的天数 | 爆发力基本面 |
| 涨停频率 | 涨停次数 ÷ 分析年数 | 标准化后可跨股比较 |
| 最大连板数 | 连续涨停天数的最大值 | ≥2 标记为"妖股基因" |
| 日均振幅 | `(high - low) / pre_close × 100` 的加权平均 | >5% 股性极活，<2% 股性偏死 |
| 炸板率 | 盘中触及涨停但收盘未封住的比例 | >50% 为典型"渣男股" |

#### 涨停质量分层

不同类型的涨停含金量不同：

| 涨停类型 | 判定条件 | 权重 |
|:---|:---|:---|
| **放量首板** | 换手率 > 10% | 高（真金白银入场） |
| **普通涨停** | 换手率 2%~10% | 中 |
| **缩量一字板** | 换手率 < 2% 或开盘=收盘=最高价 | 低（利好消息的无量拉升） |
| **尾盘偷袭板** | *当前版本暂未精确实现* | 低 |

#### 评分逻辑

基础分 50，根据以下因素加减：
- 涨停频率每增加 1 次/年 → +5（上限 +20）
- 最大连板 × 8 → +（上限 +16）
- 振幅 > 5% → +10，振幅 < 2% → -15
- 炸板率 > 50% → -10
- 涨停质量评分的 4% 转化为加分

---

### 4.2 维度二：看"习惯" —— 均线契合度与趋势延续性

**核心目标**：找到股票的趋势规律和"真命天子均线"，作为止盈止损的依据。

#### 计算指标

| 指标 | 计算方式 | 诊断意义 |
|:---|:---|:---|
| 趋势类型 | 综合判定 | "阶梯上涨" / "A字杀" / "混合型" |
| 平均上涨波段天数 | 收盘连续在 20 日均线上方的天数统计 | 波段越长越适合持有 |
| A字杀次数 | 3日涨幅 > 15% 后 5 日跌幅 > 10% | 越多越危险 |
| 真命天子均线 | 回调触碰后反弹成功率最高的均线 | 买入和止损的核心依据 |

#### 真命天子均线检测算法

对 MA5、MA10、MA20、MA60 分别计算：

1. 识别"触碰事件"：股价从均线上方跌至均线 ±1% 范围内
2. 检查后续 5 个交易日是否站回均线上方
3. 成功率 = 反弹成功次数 ÷ 总触碰次数
4. 选出成功率最高的均线作为"真命天子"

**实战应用**：如果某股票的 20 日线反弹成功率 > 70%，则每次回调到 20 日线附近就是买入机会，跌破就止损。

#### 趋势类型判定

```
if A字杀 >= 3 次 且 平均波段 < 10 天:
    → "A字杀"型（暴涨后必暴跌，连涨两天就该卖）
elif 平均波段 >= 20 天 且 A字杀 <= 1 次:
    → "阶梯上涨"型（敢于在回调时加仓）
else:
    → "混合型"
```

### 4.3 维度三：看"饭量" —— 量价配合度

**核心目标**：通过成交量和换手率判断资金性质，区分游资股和机构股。

#### 计算指标

| 指标 | 计算方式 | 诊断意义 |
|:---|:---|:---|
| 资金类型 | 基于平均换手率判定 | "游资主导" / "机构控盘" / "混合型" |
| 缩量回调比 | 下跌日均量 ÷ 上涨日均量 | <0.5 为优质缩量（主力未走） |
| 近期活跃度 | 近 3 月振幅 ÷ 近 3 年振幅 | >1.5 觉醒，<0.6 死亡 |

#### 资金类型判定

| 类型 | 条件 | 特点 |
|:---|:---|:---|
| **游资主导** | 平均换手 > 10% 或高换手天数 > 20 | 快进快出，随时崩盘 |
| **机构控盘** | 平均换手 < 3% 且最高 < 10% | 锁仓稳定，适合中长线 |
| **混合型** | 其他 | 需结合其他维度判断 |

#### 近期活跃度对比（建议 2）

比较近 3 个月与近 3 年的平均振幅：

| 活跃度比值 | 判定 | 含义 |
|:---|:---|:---|
| > 1.5 | **股性正在觉醒** 🔥 | 可能有资金入场，值得关注 |
| 0.6 ~ 1.5 | **股性稳定** | 维持历史水平 |
| < 0.6 | **股性正在死亡** ☠️ | 正在沦为僵尸股，警惕 |

> **数据覆盖提示**：`daily_basic`（换手率）仅从 2023 年开始。若数据不足，报告中会标注。

---

### 4.4 维度四：看"江湖地位" —— 板块联动与大盘逆反

**核心目标**：通过与大盘指数的对比，判断股票是龙头还是弱势股。

#### 计算指标

| 指标 | 计算方式 | 诊断意义 |
|:---|:---|:---|
| Beta 系数 | 个股收益率与指数收益率的协方差 / 指数方差 | >1 放大波动，<1 防御性 |
| 大盘跌日收益 | 大盘 pct_chg < -1% 时，个股平均收益 | 越高越抗跌 |
| 大盘涨日收益 | 大盘 pct_chg > 1% 时，个股平均收益 | 越高越能跟涨 |
| 抗跌评分 | 基于抗跌比率的归一化评分 (0-100) | |
| 领涨评分 | 大盘上涨日跑赢大盘的比例 (0-100) | |

#### 定位判定

| 定位 | 条件 | 特点 |
|:---|:---|:---|
| **龙头** 👑 | 抗跌 > 65 且领涨 > 55 | 跟涨不跟跌，加入核心池 |
| **跟随** | 其他 | 与大盘同步 |
| **弱势** ❌ | 抗跌 < 35 且领涨 < 45 | 跟跌不跟涨，建议拉黑 |

## 五、综合归类算法

### 5.1 评分体系

每个抽屉有独立的评分函数，计算该股票有多像对应类型：

**抽屉 B（妖股）评分要素**：
- 妖股基因（连板≥2）→ +30
- 涨停频率（每次/年 → +5，上限 25）
- 游资主导 → +15
- 高振幅（>5%） → +10
- 涨停质量 → 按比例加分

**抽屉 D（僵尸股）评分要素**：
- 机构控盘 + 优质缩量 → **直接归零**（白马股不是僵尸）
- 低振幅（<2%） → +20
- 低换手（非机构） → +25
- 弱势定位 → +25（核心特征）
- 股性正在死亡 → +15

**抽屉 C（渣男）评分要素**：
- 高炸板率（>50% → +25，>30% → +15）
- A字杀频发（≥3次 → +20）
- 均线无效（成功率<40% → +10）
- 高振幅 + 高炸板 → +15

**抽屉 A（白马）评分要素**：
- 基础分 15（默认兜底）
- 机构控盘 → +25（核心特征）
- 优质缩量 → +20
- 阶梯上涨 → +15
- 均线有效（>60% → +12，>40% → +5）
- 龙头定位 → +10

### 5.2 归类置信度

最终归类不只给出一个字母，还附带**置信度百分比**和**次要特征**：

```
归类: 🐎 抽屉A — 白马/核心资产 (置信度 54.5%)
次要特征: D(僵尸股) 22.7% | C(渣男) 15.2% | B(妖股) 7.6%
```

置信度 = 该类别评分 ÷ 所有类别评分之和 × 100%

> **边界情况处理**：当置信度接近 50% 时，说明股票处于两个类别的边界。此时应同时参考主要和次要特征，灵活制定策略。

## 六、HTML 报告

### 6.1 单只股票报告

报告结构（自上而下）：

1. **头部**：股票名称 + 代码 + 板块 + 行业 + 分析区间
2. **归类卡片**：抽屉标识 + 置信度 + 战术建议 + 次要特征
3. **四维雷达图**：ECharts 雷达图展示四个维度评分
4. **K线走势图**：交互式 K 线图，叠加以下标注：
   - 🔴 红色三角：涨停日
   - 🟡 黄色菱形：炸板日
   - 🔵 蓝色线：真命天子均线
   - 支持缩放和滑块浏览
5. **四个维度详情面板**：每个维度的指标表格 + 文字诊断

### 6.2 行业批量报告

1. **统计概览**：四个抽屉各有多少只股票
2. **饼图**：归类分布
3. **汇总表格**：股票名 | 归类 | 四维评分 | 置信度 | 诊断摘要

### 6.3 技术实现

- 使用 **ECharts CDN** 渲染图表
- 内联 CSS 暗色主题
- **单 HTML 文件**，无外部依赖，打开即用
- 报告默认保存在 `reports/` 目录

## 七、使用方法

### 7.1 命令行（推荐）

```bash
# 进入项目根目录
cd vcp_akshare

# 单只股票分析
python scratch/analyze_personality.py --ts_code 600519.SH

# 按行业批量分析
python scratch/analyze_personality.py --industry 白酒

# 指定报告输出目录
python scratch/analyze_personality.py --ts_code 600089.SH --output_dir my_reports
```

### 7.2 Python API

```python
from src.data.reader.stock_reader import StockReader
from src.analysis.stock_personality import StockPersonalityAnalyzer
from src.analysis.personality_config import PersonalityConfig
from src.analysis.personality_report import PersonalityReportGenerator

# 初始化
reader = StockReader()
config = PersonalityConfig(lookback_days=750)  # 可自定义参数
analyzer = StockPersonalityAnalyzer(reader, config)

# 单只分析
result = analyzer.analyze("600519.SH")
if result:
    print(f"{result.name}: {result.category_emoji} {result.category_name}")
    print(f"真命天子均线: {result.habit.best_ma}日线")
    print(f"资金类型: {result.volume_profile.capital_type}")

# 生成 HTML 报告
reporter = PersonalityReportGenerator()
reporter.generate_single(result, "reports/maotai.html")

# 按行业批量分析
results = analyzer.analyze_industry("白酒")
reporter.generate_batch(results, "白酒行业分析", "reports/baijiu.html")

# 自定义股票列表批量分析
codes = ["600519.SH", "000858.SZ", "603369.SH"]
results = analyzer.analyze_batch(codes)
```

### 7.3 自定义配置

```python
config = PersonalityConfig(
    lookback_days=500,            # 分析窗口改为 2 年
    high_turnover_threshold=20.0, # 高换手阈值调至 20%
    a_kill_rise_pct=20.0,         # A字杀涨幅阈值调至 20%
    ma_windows=[5, 10, 20, 60, 120],  # 增加 120 日均线
)
analyzer = StockPersonalityAnalyzer(config=config)
```

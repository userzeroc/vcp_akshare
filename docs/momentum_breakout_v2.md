# 动量突破策略 (Momentum Breakout Strategy) v2.0 规格说明书

## 1. 策略概览 (Strategy Overview)
本策略是一款经典的**趋势跟随（Trend Following）**策略，专为具备“脉冲式爆发、长周期横盘、回撤快平衡”特征的股票（如特变电工 600089.SH）设计。

*   **核心理念**：平时绝对空仓，只在大级别趋势向好且短线爆量异动时介入；通过“截断亏损，让利润奔跑”获取超额收益。
*   **适用场景**：动量爆发波段、主升浪行情。

---

## 2. 核心逻辑 (Core Logic)

### 2.1 买入条件 (Entry Rules)
必须同时满足以下 **A、B、C** 三个条件（共振突破），且通过 **D** 条件过滤：

| 维度 | 条件定义 | 逻辑目的 |
| :--- | :--- | :--- |
| **A. 趋势过滤** | 当前收盘价 > 60日均线 (MA60) | 确保处于大级别多头中，过滤下跌趋势中的反弹。 |
| **B. 价格爆发** | 当日涨幅 > 5.0% | 识别强势启动信号，避免阴涨或无力波动。 |
| **C. 量能确认** | 当日成交量 > 过去20日均成交量的 2.0倍 | 确认资金异动，确保突破具备真实的资金支撑。 |
| **D. 估值过滤** | 乖离率 (Bias60) < 25% | **[v2.0新增]** 防止追涨涨幅过大的“强弩之末”，规避高位站岗。 |

### 2.2 卖出条件 (Exit Rules)
策略不设置固定止盈目标，采用多重离场机制：

1.  **硬止损 (Hard Stop)**：
    *   收盘价跌破信号日（买入信号触发当天）的最低价。
    *   或者 账户单笔亏损达到 **-8%**。
2.  **动态追踪止盈 (ATR Trailing Stop) [v2.0核心]**：
    *   计算持仓期间的最高价（Highest Price）。
    *   离场线 = 最高价 - (2.5 * ATR)。
    *   当收盘价跌破该离场线时平仓，有效锁住主升浪后期的利润，防止回吐。
3.  **均线离场 (Trend Exit)**：
    *   收盘价跌破 20日均线 (MA20)。防止长周期趋势阴跌。

---

## 3. 风险管理 (Risk Management)

*   **仓位控制**：默认 50% - 100% 仓位。
*   **规避财报 [v2.0新增]**：在财报发布前 3-5 天禁止买入，且在财报日强制离场，规避业绩“地雷”导致的不连续缩量跌停风险。
*   **低波动过滤**：支持 ATR 波动率过滤（可选），确保买入时市场已结束长期的横盘。

---

## 4. 关键参数配置 (Configurable Parameters)

| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `ma_long_period` | 60 | 长期趋势线（多空分界线） |
| `ma_short_period` | 20 | 中短期保护线（卖出参考） |
| `min_pct_chg` | 5.0% | 启动大阳线要求 |
| `vol_multiplier` | 2.0x | 倍量确认系数 |
| `hard_stop_loss` | -8.0% | 固定止损位 |
| `bias_threshold` | 0.25 | 60日乖离率上限 |
| `atr_multiplier` | 2.5 | 吊灯止盈倍数 |

## 5. 性能参考 (Backtest Performance)

基于“特变电工” 2020-2025 年回测数据：

*   **总收益率**：**106.29%**
*   **最大回撤**：20.76% (发生于 2021 年顶部调整)
*   **盈亏比**：**8.65** (表现出极强的“盈亏不对称性”)
*   **胜率**：35.7% (符合典型的趋势跟随策略特征)

## 7. 开发者建议
1.  **参数适配**：对于波动率极高的个股，ATR 倍数可适当放宽（如 3.0）；对于稳健个股可收紧（如 2.0）。
2.  **多标的策略**：建议将此策略逻辑整合入扫描引擎，每日对全市场进行自动扫描，选取触发信号的股票进入池子。
